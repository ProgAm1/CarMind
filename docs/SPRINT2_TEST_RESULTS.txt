REPRODUCE
---------
Requirements: JDK 17+, Android SDK 37 / Build Tools 36.0.0, SDK configured
through Android Studio or ANDROID_HOME. See README for Firebase setup.

./gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest assembleRelease lintDebug

On an isolated signed-out emulator (API 36 was used):
./gradlew connectedDebugAndroidTest

For screenshots, Gradle's managed test cleanup can uninstall the app and
remove its external files. Install and run the suite directly, then pull:

adb -s <emulator-serial> install -r app/build/outputs/apk/debug/app-debug.apk
adb -s <emulator-serial> install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s <emulator-serial> shell am instrument -w com.carmind.app.test/androidx.test.runner.AndroidJUnitRunner
adb -s <emulator-serial> pull /sdcard/Android/data/com.carmind.app/files/sprint2-screenshots/

Use a dedicated test emulator, not a user's signed-in phone. UI assertions
currently use English labels, so reproduce with an English test locale.

Standard generated reports:
app/build/test-results/testDebugUnitTest/
app/build/reports/tests/testDebugUnitTest/index.html
app/build/reports/androidTests/connected/debug/index.html
app/build/reports/lint-results-debug.html

EVIDENCE BOUNDARIES
-------------------
Dashboard screenshots use a non-exported debug-only test activity, the actual
dashboard layout/renderer, and explicitly marked simulated data. Its actions
are disabled. Release has no sample-data screen or authentication bypass.

Not executed: physical Bluetooth pairing/permission flow, SPP compatibility
with the photographed reader, actual vehicle responses, real disconnect and
cancellation behavior, live Firebase sign-in, or teammate registration.
See physical acceptance cases P01-P08 in docs/SPRINT2.md and the Word report.

The local google-services.json was unavailable. The APKs therefore build
without Firebase configuration, and ordinary sign-in is unavailable until
the team supplies that file and rebuilds. The release APK is unsigned.

The prior paused, untracked Sprint 1 RegistrationValidationTest draft was
moved to ignored tmp/paused-sprint1/ because no registration implementation
exists in this checkout. It is not included in these counts or source ZIP.
