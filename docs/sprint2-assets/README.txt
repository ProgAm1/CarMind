The four PNGs in sprint2-screenshots were captured from the implemented Android
dashboard using Sprint2DeviceTest and the debug-only DashboardPreviewActivity.
They show the same XML layout and renderer used by HomeActivity.

01-reader-screen.png  — reader controls and initial dashboard
02-reading-screen.png — RPM, speed and coolant values
03-history-screen.png — local history
04-empty-screen.png   — no readings available

All have the visible "UI TEST PREVIEW • SIMULATED DATA" banner. The values and
demo@example.com account label are fixtures, not vehicle measurements or a
real user account. These images verify UI rendering only. Do not present them
as proof of live Bluetooth connection, cloud authentication or field testing.

The PowerPoint contains simple Arabic speaker notes explaining the hardware
and software roles. Its text and testing table are editable.
